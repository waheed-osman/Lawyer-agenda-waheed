# أجندة المحامي القانونية (Lawyer's Legal Agenda) — الإصدار 2

تطبيق Flutter لأندرويد، يعمل بالكامل بدون إنترنت (SQLite محلي)، واجهة عربية RTL، ووضعان فاتح/داكن.
تفاصيل الهيكلة وخريطة المميزات: [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md)

## الجديد في الإصدار 2
- **لوحة التحكم:** ملخص اليوم، تنبيه داخلي بجلسات اليوم وغدًا، عدادات القضايا، المتبقي من الأتعاب، المواعيد القريبة.
- **المواعيد العامة** (اجتماع، سداد رسوم، استلام صورة حكم) في التقويم، بوقت اختياري وتنبيه محلي.
- **المذكرات:** تبويب داخل كل قضية لتدوين مسودات الدفاع والطعون وملاحظات العمل، مصنّفة وقابلة للبحث والنسخ والمشاركة.
- **الماليات:** أتعاب، دفعات، أمانات، مصروفات قضائية؛ المتبقي ورصيد الأمانات لكل قضية ولكل موكل ولكل المكتب.
- **التصدير:** PDF (عرض/طباعة/حفظ) أو نص للمشاركة: تقرير قضية، كشف حساب موكل، أجندة فترة، قائمة قضايا.
- **الموكل:** بريد إلكتروني، وأزرار اتصال وواتساب وبريد.
- أنواع قضايا إضافية: جنح توريد، جنايات، أحوال شخصية.

## كيف تحدّث تطبيقك الحالي (GitHub)
1. فُكّ ضغط الملف، وادخل المجلد `lawyer_agenda`.
2. افتح مستودعك على GitHub ← **Add file** ← **Upload files**، واسحب إليه **كل محتويات المجلد** (الملفات و`lib` و`tool` و`docs`). الملفات المتطابقة بالاسم تُستبدل.
3. أهم ملفين لازم يتحدّثوا: `pubspec.yaml` (حزم جديدة) و`tool/setup_android.py`.
4. اضغط **Commit changes**.
5. تبويب **Actions** ← **Build APK** ← **Run workflow**، وبعد النجاح نزّل `lawyer-agenda-apk` من Artifacts.
6. ثبّت الـ APK **فوق** النسخة القديمة (بدون حذفها) وبياناتك ستبقى، والترقية لقاعدة البيانات تلقائية.

> قبل التحديث: من الإعدادات ← **نسخ احتياطي** وخزّن الملف خارج الهاتف.

ملاحظة: المجلدات المخفية (`.github` و`.gitignore`) لا تُرفع بالسحب والإفلات. ملف الـ workflow عندك على GitHub شغّال بالفعل (يثبّت Flutter 3.27.4)، ولا تحتاج لتغييره.

## البناء على جهازك
```bash
flutter create --platforms=android --org com.lawyer.agenda --project-name lawyer_agenda .
python3 tool/setup_android.py      # أذونات + بصمة + desugaring + الاسم العربي
flutter pub get
flutter build apk --release        # الناتج: build/app/outputs/flutter-apk/app-release.apk
```
يحتاج Flutter 3.22 أو أحدث (المجرَّب: 3.27.4).

## ملاحظات
- **التوقيع:** الـ APK موقّع بمفتاح debug، يكفي للاستخدام الشخصي.
- **التنبيهات:** الجلسة: قبلها بيوم 6 مساءً وصباحها 7:30. الموعد: قبله بيوم 6 مساءً، وقبله بساعة (أو 8 صباحًا إن كان بلا وقت). على هواتف Xiaomi/Huawei/Oppo/Infinix فعّل التشغيل التلقائي واستثنِ التطبيق من توفير البطارية.
- **كلمة المرور** لا تُسترجع إن نُسيت. والنسخة الاحتياطية JSON **غير مشفرة**.
- **PDF:** يعتمد على محرك الطباعة في أندرويد، ويدعم العربية RTL.
- النماذج القانونية المضمّنة هياكل عامة تحتاج مراجعتك.
